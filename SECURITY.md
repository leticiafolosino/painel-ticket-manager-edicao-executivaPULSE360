# Segurança e uso responsável

Este repositório contém uma demonstração estática para avaliação visual e funcional.

- Não publicar chamados reais, nomes de solicitantes, e-mails, credenciais, endereços, números de patrimônio ou dados de clientes/contratos.
- Não colocar tokens, senhas, arquivos de exportação do sistema de chamados ou planilhas operacionais no repositório.
- O painel não tem autenticação de servidor nem controle de acesso corporativo. A alternância entre perfis é uma perspectiva de interface e não deve ser tratada como autorização de segurança.
- A publicação via GitHub Pages pode ficar acessível publicamente, conforme a configuração e o plano da conta. Revise todo o conteúdo antes de publicar.
- Para avaliação com liderança, prefira dados demonstrativos, sem qualquer informação identificável ou confidencial.
